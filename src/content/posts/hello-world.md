I built this site as a lightweight home for my work across IIoT edge platforms, manufacturing data engineering, backend systems, and EdgeAI experiments.

The first goal is simple: make the important parts of my resume easier to explore. A PDF resume is useful, but it compresses everything into a fixed format. A website gives more room for project notes, architecture decisions, lessons learned, and the kind of technical context that does not always fit into a one-page document.

The stack is intentionally straightforward: React, Vite, Material UI, Markdown posts, GitHub Pages deployment, and Docker for local preview. The content is data-driven, so updating profile details, projects, experience, education, awards, or posts is mostly a matter of editing structured files.

I plan to use the blog section for short notes on manufacturing data platforms, AI agents, MCP, edge systems, and the practical work of making factory data usable.
